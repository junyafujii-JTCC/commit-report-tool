コミットレポート（コミネコ）— 完成イメージ資料

以下は静的プレビュー用です。ブラウザでスライドを開き、必要なら印刷から PDF 保存できます。

  • 完成イメージスライド（HTML・全ページ）
  • PDF（同内容の生成例）
  • 市場デイリーアップデート（1枚ボード・左2×2チャート／右ニュース） — market-brief-news.json で上書き（npm run fetch:market-news：M&A・IPO=NewsAPI、海外=Yahoo!ニュース RSS＋見出しフィルタ、要 NEWS_API_KEY）。株価終値・指数化は npm run fetch:market-prices → market-brief-prices.json（日本=Yahoo Finance chart・キー不要、米国=Polygon API Key）
  • 瀧さん — 日報カウンター（営業日カウント・「戻して」でリセット）
