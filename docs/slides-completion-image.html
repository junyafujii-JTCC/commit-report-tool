各要素の「画面」のイメージ

実UIのスクショではなく、完成時に何がどこで起きるかのラフ。

GitHub · リポジトリ
コミット一覧・ブランチ・差分がここに蓄積される。
ツールは API で「昨日分」を取得。
GitHub Actions
スケジュールで起動。フォント・Node・Playwright を整え、Claude にプロンプトを渡す。
Claude（分析・図解）
コミットを要約し、HTML 図解を複数枚生成 → スクリーンショットで PNG 化。
Slack
チャンネルに「期間・対象・ハイライト」テキストと画像が一括で届く。

このスライド資料の使い方

  • ブラウザで開き、印刷 → PDF 保存（余白なし・背景グラフィック ON）で PPT ワイドに近い PDF が得られます
  • スライド2は、添付の「市場サマリー型」レイアウト（3パネル・水色・表＋小型チャート）をコミットレポート用に置き換えた例です
  • トレカセンター緑のスライドが必要なら、スライド1・3以降の配色をそのまま使えます
